# LangGraph Academy MVPs (M0 - M6)

Repositorio con los entregables y MVPs reproducibles para los Módulos 0 al 6 del curso **Introduction to LangGraph**.

## Requisitos Previos

- Python >= 3.12
- Gestor de paquetes `uv`
- Clave de API de Google Gemini (`GOOGLE_API_KEY`)

## Configuración e Instalación

1. **Clonar el repositorio y entrar a la carpeta:**
   ```bash
   git clone [https://github.com/Jean-Paredes/langgraph-academy-mvps.git](https://github.com/Jean-Paredes/langgraph-academy-mvps.git)
   cd langgraph-academy-mvps
