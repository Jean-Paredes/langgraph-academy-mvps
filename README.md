# LangGraph Academy MVPs (M0 - M6)

Repositorio con los entregables y MVPs reproducibles para los Módulos 0 al 6 del curso **Introduction to LangGraph**.

## 🚀 Requisitos Previos

- Python >= 3.12
- Gestor de paquetes `uv`
- Clave de API de Google Gemini (`GOOGLE_API_KEY`)
